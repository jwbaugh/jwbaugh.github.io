Vitri 2.0 - Download Files

If you are new to Vitri, try starting out with the sequential code before moving to the distributed one. Customizing your GA works the same in either case, so there is no effort lost in beginning with the sequential code and later moving to the distributed one.
  • ga.tar.gz - sequential GA code (compressed tar file)

  • sdga.tar.gz - synchronous distributed GA code (compressed tar file)
